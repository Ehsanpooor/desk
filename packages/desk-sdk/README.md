# @elva/desk-sdk

The contract between the ELVA Desk and the apps that open inside it.

- `@elva/desk-sdk` — types, `defineDeskApp`, and the guards that refuse to mount anywhere but the desk.
- `@elva/desk-sdk/react` — `DeskProvider`, `useDesk`, `useReadable`, `TitlebarPortal`, `WindowPortal`.
- `@elva/desk-sdk/host` — used by the desk only.

Read `docs/APP_ONBOARDING.md` in the desk repo before building an app against this.
